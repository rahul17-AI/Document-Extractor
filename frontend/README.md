# Frontend - Comply Filing Intelligence UI

Single-page React application built with Vite and Tailwind CSS. Provides a clean, modern interface for uploading compliance filings, viewing structured JSON, reading extracted sections, and downloading results.

## Folder Structure

- **`src/`**: Application source code
  - **`components/`**: Modular UI components (UploadZone, DocumentMetrics, SectionCard, JsonViewer, JsonModal, SectionNav, Header, LoginScreen)
  - **`App.jsx`**: Main application state & orchestration
  - **`main.jsx`**: React DOM entry point
  - **`index.css`**: Tailwind CSS imports and utility styling
- **`public/`**: Static assets including `sample_amgn_filing.pdf`
- **`index.html`**: HTML application entry point
